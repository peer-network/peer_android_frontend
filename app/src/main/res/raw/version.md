# 📝 Release Notes

### 🚀 Highlights
This release focuses on improving the authentication and onboarding experience, ensuring smoother access and consistent design across the user journey.

---

### ✨ New Features & Updates

- **Registration Flow – 1st Iteration**  
  Introduced the first version of the updated registration process with an improved user experience and streamlined steps for onboarding new users.

- **Login + Remember Me**  
  Updated design and functionality for the login screen. Added “Remember Me” functionality for easier and faster re-authentication.

- **Forgot Password**  
  Refreshed the design and synced the functionality to provide a consistent and user-friendly password recovery experience.

- **Logout Flow**  
  Enhanced logout flow to ensure consistency across sessions and alignment with the updated authentication design.

- **In-App Release Notes**  
  Added a new section within the app where users can view the latest release notes directly — improving transparency and engagement.

---

### 🧩 Technical Improvements
- Unified UI components for all authentication-related screens.
- Improved error handling and feedback across registration and login workflows.
- Internal synchronization of authentication logic for maintainability.

### 🧠 Known Issues
- None reported at this time.
