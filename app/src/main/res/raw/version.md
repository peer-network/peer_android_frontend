# 📝 Release Notes

### 🚀 Highlights
This release introduces powerful new advertising features for Pinned Posts, along with visual updates and bug fixes to improve the overall user experience.

---

### ✨ New Features & Updates

- **Create a Pinned Post Ad using Peer tokens - my posts**  
  You can now create Pinned Post Ads directly from your own posts using Peer tokens. This streamlines the promotion process and gives you more control over advertising your content.

- **View a Pinned Ad Stats - my posts**  
  Track the performance of your Pinned Ads with dedicated statistics. View engagement metrics and insights directly from your posts to understand your ad's impact.

---

### 🧩 Technical Improvements
- Enhanced ad creation workflow for better performance and reliability.
- Improved data synchronization between ListPosts and advertisement systems.
- Optimized UI rendering for pinned posts across different screen sizes.

---

### 🧠 Known Issues
- None reported at this time.
